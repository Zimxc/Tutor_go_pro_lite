# TutorWise Lite

TutorWise Lite — навчальний сайт для пошуку викладачів і запису на заняття. Проєкт створено для практики Django: роботи з користувачами, формами, базою даних і HTML-шаблонами.

Інтерфейс українською мовою. Час занять вказано за Києвом, ціни — у гривнях.

## Можливості

Під час реєстрації користувач обирає роль учня або викладача.

**Учень може:**

- Шукати викладачів за ім’ям або предметом, переглядати їхні профілі та ціни.
- Підписуватися на викладачів і бачити їх у списку «Мої викладачі».
- Надсилати заявку на вільний час, стежити за її статусом і скасовувати заняття.
- Переглядати домашні завдання та відкривати посилання на зустріч зі сторінки заняття.

**Викладач може:**

- Редагувати опис і фото профілю, обирати предмети з каталогу та вказувати ціни.
- Додавати вільні години до розкладу й прибирати незайняті години.
- Підтверджувати або відхиляти заявки учнів, скасовувати заняття та позначати проведені як завершені.
- Додавати посилання на зустріч, створювати, редагувати й видаляти домашні завдання для підтверджених або завершених занять.

Заняття триває одну годину. Нові назви предметів додає адміністратор через панель керування Django.

## Технології

- Python 3.12+ і Django 5.2.
- SQLite для зберігання даних.
- Django Templates, Forms, ORM та вбудована авторизація.
- HTML, звичайний CSS і невелика кількість JavaScript.
- Pillow для роботи з фотографіями.

## Встановлення та запуск

Потрібен встановлений Python 3.12 або новіший. Відкрийте PowerShell у папці `tutor-wise-lite`, де знаходиться `manage.py`.

Створіть віртуальне середовище поруч із проєктом і встановіть залежності:

```powershell
py -3.12 -m venv ..\tutor-wise-lite-venv
..\tutor-wise-lite-venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Якщо PowerShell не дозволяє активувати середовище, замість `python` у наступних командах використовуйте `..\tutor-wise-lite-venv\Scripts\python.exe`.

Підготуйте базу даних, додайте початкові предмети та запустіть сайт:

```powershell
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8001
```

Відкрийте [сайт у браузері](http://127.0.0.1:8001/) та зареєструйтеся.

Для доступу до [панелі адміністратора](http://127.0.0.1:8001/admin/) створіть обліковий запис:

```powershell
python manage.py createsuperuser
```

Цю команду виконайте перед запуском сервера або в іншому терміналі з активованим середовищем. Для наступних запусків достатньо активувати середовище й виконати команду `runserver`.

## Структура проєкту

- `accounts/` — реєстрація, вхід і облікові записи.
- `tutors/` — профілі викладачів, предмети, ціни та підписки.
- `lessons/` — розклад, заявки, заняття й домашні завдання.
- `config/` — налаштування проєкту та маршрути сторінок.
- `templates/` — HTML-шаблони зі спільним `base.html`.
- `static/` — CSS і JavaScript.
- `media/` — завантажені фотографії.
- `manage.py` — запуск сервера та інших команд Django.
- `requirements.txt` — залежності проєкту.
- `db.sqlite3` — локальна база даних; створюється під час першого виконання міграцій.
